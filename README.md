# creattiva-media

Immagini pubbliche dei post social di Creattiva srl. Metricool le scarica da qui tramite i link "raw".

Regole:
- Solo media già approvati per la pubblicazione.
- Niente bozze, documenti interni, dati di clienti o del personale.
- Percorso: `<canale>/<anno-mese>/<rubrica>-<numero>.<estensione>`
- Foto stock in `stock/`: solo con licenza che consente l'uso commerciale, con autore e fonte in `stock/CREDITS.md`.

Contenuti scritti con l'ausilio dell'AI con la supervisione di Gianluca Falduto.

Strumenti in `tools/`: codice di Creattiva per preparare i contenuti (per esempio `tools/reelcheck`, il controllo dei video brevi prima della pubblicazione). Non sono media: valgono le regole del README di ogni strumento.
